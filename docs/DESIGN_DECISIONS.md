# Design Decisions


## Owl System

### Nest Placement

Decision:
Nests attach to trees/leaves, not hanging.

Reason:
More natural and easier AI.


## Breeding

Decision:
Use wildlife style breeding.

Flow:

Rabbit feeding
↓
Nest creation
↓
Egg
↓
Baby owl


## World Generation

Decision:
Only affect new chunks.

Reason:
Compatible with existing worlds.

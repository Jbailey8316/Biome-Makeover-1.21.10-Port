# Final Owl System Roadmap

Completed foundation:
- Owl taming
- shoulder perching
- hunting
- breeding groundwork
- nest claiming
- nest sleeping
- basket-style nest model
- sleeping pose lock
- creative/spectator immunity
- player disturbance handling

Final feature pass targets:
- Dark Oak Forest natural empty nest generation
- nest attachment validation (tree/leaves only)
- empty nest reuse by adults
- breeding uses existing nest when available
- breeding creates new nest request when unavailable
- egg state in nest
- visible egg model
- incubation behavior
- parent owl protection response
- silk touch/shears recovery rules
- wake animation polish

Design rules:
- Owls should feel like wildlife, not hostile mobs.
- Sleeping owls remain still with rare subtle idle movement.
- Empty nests are reusable.
- Once a nest is broken, ownership is cleared.

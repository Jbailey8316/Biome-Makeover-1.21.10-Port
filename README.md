# Biome Makeover 1.21.10

A Fabric 1.21.10 port and expansion of Biome Makeover.

The goal is to preserve the original biome additions while rebuilding each biome as an independent module.

## Project Goals

- Port original Biome Makeover features
- Maintain original biome identity
- Expand ecosystems with new mechanics
- Build each biome independently

## Current Focus

Dark Forest Expansion

Includes:
- Original Dark Forest features
- Owl ecosystem expansion
- New wildlife mechanics
